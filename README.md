# Personal Portfolio Website
Created by Ella Zaputil for BAIS:3300 Digital Product Management at the University of Iowa

## 📌 Overview
This project is a personal portfolio website designed to showcase my professional experiences, technical skills, and featured work. As part of my Digital Product Management course, I created this site using modern web development tools and integrated analytics to better understand user interactions.

The goal of this project was to create a clean, professional online presence while practicing product management, user-centered designed, and iterative improvement.

## Technologies Used
- **HTML5** - page structure, layout
- **CSS** - custom styling, responsive design, typography
- **Google Analytics** - tracking user behavior, traffic insights, and engagement metrics

## What I Learned
- Front-end web development using HTML and CSS
- Applying product thinking to digital experiences
- Using Google Analytics to track KPIs and user behavior
- Designing with the user journey in mind
- Iterative testing and improvement
